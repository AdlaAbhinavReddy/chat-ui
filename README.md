# Chat UI

A simple, responsive chat interface built with pure HTML and CSS, styled to resemble a messaging app conversation thread.

## ✨ Features

- Chat bubble layout differentiating sent (`from`) and received (`to`) messages
- Custom chat background image
- Rounded message bubbles with distinct colors for each sender
- Google Fonts (Roboto) integration
- Fully responsive using `vh` / `vw` units

## 🛠️ Built With

- HTML5
- CSS3
- Google Fonts

## 🚀 Getting Started

### Prerequisites

Just a web browser — no build tools or dependencies required.

### Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/chat-ui.git
   ```
2. Navigate into the project folder
   ```bash
   cd chat-ui
   ```
3. Open `index.html` in your browser
